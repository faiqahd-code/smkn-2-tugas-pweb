WEBSITE SMKN 2 PADANG — HTML + BOOTSTRAP

ISI FOLDER
- index.html  : halaman Beranda
- berita.html : halaman Berita
- profil.html : halaman Profil
- jurusan.html: halaman Jurusan
- style.css   : desain/tampilan website
- script.js   : bantuan navigasi aktif

CARA MENJALANKAN DI VISUAL STUDIO CODE
1. Ekstrak file ZIP ini.
2. Buka Visual Studio Code.
3. Klik File > Open Folder, lalu pilih folder website_smkn2_padang.
4. Buka file index.html.
5. Klik kanan di dalam file lalu pilih "Open with Live Server" jika ekstensi Live Server sudah terpasang.
   Jika belum, bisa buka file index.html langsung dari File Explorer dengan browser.
6. Klik menu Beranda, Berita, Profil, dan Jurusan untuk mencoba perpindahan halaman.

CATATAN
- Bootstrap dimuat dari CDN, jadi koneksi internet dibutuhkan agar styling Bootstrap aktif.
- Foto menggunakan URL gambar online, jadi koneksi internet dibutuhkan untuk melihat foto.
- Isi halaman berita adalah contoh tampilan tugas; periksa website resmi sekolah untuk berita terkini.
- Fasilitas yang dicantumkan di halaman Profil merupakan contoh penyajian dan sebaiknya disesuaikan dengan data resmi.
- Website ini adalah desain tugas siswa, bukan website resmi SMKN 2 Padang.
